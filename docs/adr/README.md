# Architecture Decision Records

Use ADRs for durable `quantities-d` decisions whose rationale must survive the
research discussion that produced them.

Research evidence belongs in `RESEARCH.md`, experiments, issues, and benchmark
artifacts. An ADR records the promoted decision, alternatives considered, and
consequences.

Suggested numbering:

```text
0001-<decision>.md
0002-<decision>.md
```
